第十四课：Foldable 与 Monoid

课程编号: 0014 | 前置知识: 第四课（列表与递归） | 预计时间: 35-40 分钟

Foldable 代表"可折叠"的数据结构，Monoid 代表"可合并"的值。它们经常一起使用。

1. 回顾：列表的 fold

-- foldl：从左到右折叠
foldl :: (b -> a -> b) -> b -> [a] -> b
foldl f acc []     = acc
foldl f acc (x:xs) = foldl f (f acc x) xs

Prelude> foldl (+) 0 [1,2,3]
6

-- foldr：从右到左折叠
foldr :: (a -> b -> b) -> b -> [a] -> b
foldr f acc []     = acc
foldr f acc (x:xs) = f x (foldr f acc xs)

Prelude> foldr (+) 0 [1,2,3]
6
Lisp
(reduce #'+ 0 '(1 2 3))
JS
[1,2,3].reduce((a,b)=>a+b, 0)
Haskell
foldl (+) 0 [1,2,3]

2. Foldable 类型类

class Foldable t where
  fold    :: Monoid m => t m -> m
  foldMap :: Monoid m => (a -> m) -> t a -> m
  foldl   :: (b -> a -> b) -> b -> t a -> b
  foldr   :: (a -> b -> b) -> b -> t a -> b

-- 任何 Foldable 类型都可以用
Prelude> foldl (+) 0 [1,2,3]
6
Prelude> foldl (+) 0 (Just 5)
5
Prelude> foldl (+) 0 Nothing
0

3. Monoid 类型类

class Monoid m where
  mempty :: m           -- 单位元（空值）
  mappend :: m -> m -> m  -- 结合操作
  mconcat :: [m] -> m   -- 合并列表

-- Monoid 可以用 (<>) 代替 mappend
(<>) = mappend

-- 常见 Monoid 实例
instance Monoid [a] where
  mempty = []
  mappend = (++)

instance Monoid (Sum Int) where  -- Sum 包装数字
  mempty = Sum 0
  mappend (Sum x) (Sum y) = Sum (x + y)

instance Monoid (Product Int) where
  mempty = Product 1
  mappend (Product x) (Product y) = Product (x * y)

4. 使用 Monoid

-- 字符串合并
Prelude> "hello" <> " " <> "world"
"hello world"

-- 列表合并
Prelude> [1,2] <> [3,4]
[1,2,3,4]

-- 使用 mconcat
Prelude> mconcat ["a", "b", "c"]
"abc"

-- Sum 和 Product
import Data.Monoid
Prelude> getSum (Sum 3 <> Sum 4)
7
Prelude> getProduct (Product 3 <> Product 4)
12

5. foldMap：折叠和映射的组合

-- foldMap = map + fold
foldMap :: (Foldable t, Monoid m) => (a -> m) -> t a -> m

-- 对每个元素应用函数，然后合并结果
Prelude> foldMap show [1, 2, 3]
"123"

-- 计算所有字符数
Prelude> foldMap length ["hello", "world"]
10

-- 检查是否所有值都为 True
Prelude> foldMap All [True, True, False]
All {getAll = False}

6. 自己实现 Foldable

data Tree a = Leaf a | Node (Tree a) (Tree a)
  deriving (Show)

instance Foldable Tree where
  foldMap f (Leaf x)   = f x
  foldMap f (Node l r) = foldMap f l <> foldMap f r

-- 现在 Tree 可以折叠了！
myTree :: Tree Int
myTree = Node (Leaf 1) (Node (Leaf 2) (Leaf 3))

Prelude> foldl (+) 0 myTree
6
Prelude> foldMap show myTree
"123"
练习 1

用 foldMap 计算一个 [Int] 中所有偶数的和。

练习 2

为 Maybe 类型解释 foldl (+) 0 (Just 5) 和 foldl (+) 0 Nothing 的结果。

练习 3

定义一个 Sum 和 Product 的 Monoid 实例，不使用 Data.Monoid。

小结

  • Foldable = 可折叠的数据结构
  • Monoid = 可合并的值（mempty + <>）
  • foldMap 同时做映射和合并
  • 列表、Maybe、Tree 都可以是 Foldable
  • Monoid 法则：单位元 + 结合律
