第六课：元组与代数数据类型

课程编号: 0006 | 前置知识: 第三课（模式匹配）、第五课（高阶函数） | 预计时间: 30-35 分钟

至此你已经见过 Haskell 的基本类型（Int、Bool、Char）和列表。列表要求所有元素类型相同。但如果你想组合不同类型的值，或者定义自己的类型呢？这就是本节课的内容。

1. 元组 (Tuple)

元组是固定大小、元素类型可以不同的复合类型。用括号和逗号创建：

Prelude> (1, "hello")
(1,"hello")
Prelude> (True, 3.14, 'a')
(True,3.14,'a')
概念：元组 vs 列表
列表元组
大小可变固定
元素类型必须相同可以不同
语法[1,2,3](1,"a")
-- 元组的类型编码了大小和元素类型
Prelude> :t (1, "hello")
(1, "hello") :: (Num a, Num b) => (a, [Char])

Prelude> :t (True, 3.14)
(True, 3.14) :: (Bool, Double)

元组操作

-- 二元组：fst / snd（只适用于二元组！）
Prelude> fst (1, "hello")
1
Prelude> snd (1, "hello")
"hello"

-- 模式匹配提取
Prelude> let (x, y) = (10, 20) in x + y
30

-- 从列表创建元组
Prelude> zip [1,2,3] ["a","b","c"]
[(1,"a"),(2,"b"),(3,"c")]
Kotlin
Pair(1, "hello")
Triple(1, 2, 3)
Haskell
(1, "hello")
(1, 2, 3)

2. 代数数据类型

Haskell 用 data 关键字定义新类型。代数数据类型 (ADT) 由两种基本构造组合而成：

Product Type（积类型）

"且"关系：类型 A 和 B 的积 = 同时有 A 和 B。

-- 一个 Point 包含一个 Double 且 另一个 Double
data Point = Point Double Double

Prelude> :t Point 3.0 4.0
Point 3.0 4.0 :: Point
Sum Type（和类型）

"或"关系：类型 A 和 B 的和 = 要么是 A，要么是 B。

-- 一个 Bool 要么是 True 要么是 False
data Bool = False | True  -- 内置定义

-- 自定义：一个 Shape 可以是 Circle 或 Rect
data Shape = Circle Double | Rect Double Double

3. 定义自己的 ADT

-- 产品类型：一个 Person 同时有 name 和 age
data Person = Person String Int

-- Sum 类型：一个 Status 要么是 Active、Inactive，要么是 Banned
data Status = Active | Inactive | Banned

-- 组合：构造函数可以"携带"积类型
data User = User String Status Int
--          name    status  age

模式匹配 ADT

greet :: User -> String
greet (User name Active _) = name ++ " is active"
greet (User name Inactive _) = name ++ " is inactive"
greet (User name Banned _) = name ++ " is banned"

Prelude> greet (User "Alice" Active 25)
"Alice is active"
Kotlin sealed class
sealed class Status { object Active : Status() object Inactive : Status() object Banned : Status() } data class User( val name: String, val status: Status, val age: Int )
Haskell
data Status = Active | Inactive | Banned data User = User String Status Int

4. Record 语法（具名字段）

用 data 的位置参数不直观。Record 语法给字段命名：

data Person = Person {
  name :: String,
  age  :: Int,
  email :: String
} deriving (Show)

-- 构造
Prelude> Person "Alice" 30 "alice@example.com"
Person {name = "Alice", age = 30, email = "alice@example.com"}

-- 访问字段（自动生成函数）
Prelude> name alice
"Alice"
Prelude> age alice
30

-- 更新（返回新值，原值不变）
Prelude> alice { age = 31 }
Person {name = "Alice", age = 31, email = "alice@example.com"}
概念：Record 更新 = 不可变复制

alice { age = 31 } 不修改 alice，而是返回一个新的 Person，只改动了 age。

对比 Kotlin：alice.copy(age = 31)

对比 Nix：alice // { age = 31 }

5. 经典例子：Maybe 和 Either

Haskell 标准库中最重要的两个 ADT：

-- Maybe：可能有值，可能没有
data Maybe a = Nothing | Just a

safeDiv :: Double -> Double -> Maybe Double
safeDiv _ 0 = Nothing
safeDiv x y = Just (x / y)

Prelude> safeDiv 10 2
Just 5.0
Prelude> safeDiv 10 0
Nothing

-- Either：成功或带错误的失败
data Either a b = Left a | Right b

divWithErr :: Double -> Double -> Either String Double
divWithErr _ 0 = Left "Division by zero"
divWithErr x y = Right (x / y)

Prelude> divWithErr 10 2
Right 5.0
Prelude> divWithErr 10 0
Left "Division by zero"
Kotlin
T? -- null safety
TypeScript
T | undefined
Haskell
Maybe T

6. deriving（自动派生）

data Color = Red | Green | Blue
  deriving (Show, Eq, Ord, Enum)

Prelude> show Red
"Red"
Prelude> Red == Red
True
Prelude> Red < Green
True
Prelude> [Red .. Blue]
[Red,Green,Blue]
概念：deriving = 自动实现

deriving (Show, Eq) 让编译器自动为你的类型生成 show（打印）和 ==（比较）的能力。

对比 Kotlin：data class 自动提供 toString()、equals()、copy()。

7. 实用模式：用 ADT 建模领域

-- 用 ADT 精确建模业务逻辑
data PaymentMethod
  = CreditCard { cardNumber :: String, expiry :: String }
  | WeChatPay
  | Alipay
  | Cash

data OrderStatus
  = Pending
  | Paid PaymentMethod
  | Shipped { trackingNumber :: String }
  | Delivered
  | Cancelled { reason :: String }

processOrder :: OrderStatus -> String
processOrder Pending = "Waiting for payment"
processOrder (Paid pmt) = "Paid via " ++ showPayment pmt
processOrder (Shipped tn) = "Shipped, tracking: " ++ tn
processOrder Delivered = "Done"
processOrder (Cancelled r) = "Cancelled: " ++ r
核心洞见：让非法状态不可表示

当你用 ADT 建模时，编译器保证你只能处理合法组合。比如你不能给 "已取消" 的订单发货——类型系统会阻止你。

这比你在 Java/Kotlin 中用 enum + 字段 要安全得多，因为有些组合在运行时才有意义。

小结

你已经学会了：

  • 元组：固定大小的异构集合
  • Product Type（积类型）："且"关系
  • Sum Type（和类型）："或"关系
  • data 关键字定义新类型
  • Record 语法：具名字段 + 自动生成访问器
  • Maybe 和 Either：标准库的 ADT
  • deriving：自动派生类型类实例
关键思维转变

ADT 是 Haskell 建模世界的核心工具。当你用 "或 + 且" 组合类型时，编译器就是你的最强代码审查员——非法状态会被编译拒绝。

对比 Kotlin：sealed class + data class 就是 Kotlin 版的 ADT，Haskell 更简洁的统一语法。
