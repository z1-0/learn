第八课：模块系统

课程编号: 0008 | 前置知识: 第七课（类型类） | 预计时间: 25-30 分钟

模块是组织 Haskell 代码的基本单位。它们控制命名空间和可见性，让你把代码分到不同文件中。

1. 模块基础

-- 文件: Geometry/Shapes.hs
module Geometry.Shapes
  ( Circle(..)     -- 导出类型和所有构造器
  , Rect(..)
  , area           -- 导出函数
  , perimeter
  ) where

data Shape = Circle Double | Rect Double Double
  deriving (Show, Eq)

area :: Shape -> Double
area (Circle r) = pi * r ^ 2
area (Rect w h) = w * h

perimeter :: Shape -> Double
perimeter (Circle r) = 2 * pi * r
perimeter (Rect w h) = 2 * (w + h)

3. qualified 导入

-- 使用 qualified 避免命名冲突
import qualified Data.Map as Map
import qualified Data.Set as Set

-- 使用时加前缀
myMap :: Map.Map Int String
myMap = Map.fromList [(1, "one"), (2, "two")]

mySet :: Set.Set Int
mySet = Set.fromList [1, 2, 3]

5. 模块结构最佳实践

-- 典型的 Haskell 项目结构
src/
  Main.hs              -- 入口文件，module Main where
  Lib.hs               -- 库模块，module Lib where
  Utils/
    String.hs          -- module Utils.String where
    File.hs            -- module Utils.File where
  Data/
    Types.hs           -- module Data.Types where
注意：文件名必须与模块名匹配。module Utils.String 必须在 Utils/String.hs 中。

小结

  • module 定义模块，import 导入模块
  • 文件名 = 模块名 + .hs
  • 可以控制导出列表，隐藏内部实现
  • qualified 避免命名冲突
  • 标准库有丰富的模块体系
