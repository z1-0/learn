第十三课：单子 Monad

课程编号: 0013 | 前置知识: 第十一课（Functor）、第十二课（Applicative） | 预计时间: 40-45 分钟

Monad 是 Haskell 中最著名的概念。它代表了"可以链式组合的计算"。如果你已经理解了 Functor 和 Applicative，Monad 只是向前一小步。

1. 从 Applicative 到 Monad

-- Applicative：并行组合
(+) <$> Just 3 <*> Just 5   -- Just 8
-- 两个计算是独立的

-- Monad：依赖组合
-- 第二个计算可以依赖第一个计算的结果
-- 这就是 do 记法的本质！

2. Monad 定义

class Applicative m => Monad m where
  (>>=)  :: m a -> (a -> m b) -> m b   -- bind
  return :: a -> m a                     -- 同 pure

-- (>>=) 读作"bind"
-- m a        ：前一个计算
-- (a -> m b) ：根据前一个结果产生新计算的函数

3. Maybe 的 Monad 实例

instance Monad Maybe where
  Nothing >>= _ = Nothing
  Just x  >>= f = f x

  return = Just

-- 链式调用 Maybe 计算
safeSqrt :: Double -> Maybe Double
safeSqrt x
  | x < 0     = Nothing
  | otherwise = Just (sqrt x)

safeRecip :: Double -> Maybe Double
safeRecip 0 = Nothing
safeRecip x = Just (1 / x)

-- 用 >>= 组合
result :: Maybe Double
result = safeRecip 4 >>= safeSqrt
-- Just 0.5

-- 用 do 记法（更清晰）
result' :: Maybe Double
result' = do
  x <- safeRecip 4
  y <- safeSqrt x
  return y

4. List 的 Monad 实例

instance Monad [] where
  xs >>= f = concatMap f xs
  return x = [x]

-- 列表推导就是 do 记法的语法糖
-- [x * 2 | x <- [1,2,3], x > 1]

-- 等价于 do
listResult = do
  x <- [1,2,3]
  guard (x > 1)
  return (x * 2)

-- 嵌套循环
pairs = do
  x <- [1,2]
  y <- ['a','b']
  return (x, y)
-- [(1,'a'),(1,'b'),(2,'a'),(2,'b')]

5. IO 的 Monad 实例

-- 你已经用过 IO Monad 了！（do 记法）
main :: IO ()
main = do
  putStrLn "Enter a number:"
  input <- getLine              -- IO String
  let num = read input :: Int   -- 纯计算
  putStrLn (show (num * 2))

-- 用 >>= 重写
main' :: IO ()
main' =
  putStrLn "Enter a number:" >>
  getLine >>= \input ->
  let num = read input :: Int
  in putStrLn (show (num * 2))

6. do 记法 vs >>=

-- do 记法
do
  x <- action1
  y <- action2 x
  z <- action3 y
  return (z + 1)

-- >>= 等价形式
action1 >>= \x ->
  action2 x >>= \y ->
    action3 y >>= \z ->
      return (z + 1)

-- do 记法只是 >>= 的语法糖！

7. Monad 法则

-- 左单位元
return x >>= f  =  f x

-- 右单位元
m >>= return    =  m

-- 结合律
(m >>= f) >>= g  =  m >>= (\x -> f x >>= g)
核心洞察：Monad 是什么？

Monad 是一个抽象计算类型类，它让你能：

  1. 将值包装到上下文中（return / pure）
  2. 将计算按顺序组合（>>= 或 do）
  3. 后续计算可以依赖前面的结果

对比 Kotlin：flatMap 在协程和集合中做的事类似 >>=。

练习 1

用 >>= 重写以下 do 记法：

do
  x <- Just 10
  y <- Just 20
  return (x + y)
练习 2

写一个函数 validateAge :: Int -> Either String Int，年龄在 0-150 之间返回 Right，否则返回 Left。然后用 >>= 组合两个验证。

练习 3

用 do 记法实现：读取两个数字，求它们的平方和。

小结

  • Monad = Applicative + >>=（bind）
  • >>= 按顺序组合计算
  • do 记法是 >>= 的语法糖
  • Maybe、List、IO 都是 Monad
  • Monad 让你在纯语言中模拟有顺序的计算
