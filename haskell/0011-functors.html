第十一课：函子 Functor

课程编号: 0011 | 前置知识: 第七课（类型类） | 预计时间: 35-40 分钟

Functor 是 Haskell 中一个基础的类型类，它代表"可以映射"的东西。你一定已经用过它多次了。

1. Functor 定义

class Functor f where
  fmap :: (a -> b) -> f a -> f b

-- 也可以使用中缀运算符 <$>
(<$>) = fmap
概念：Functor 是什么？

Functor 是一个"容器"或"上下文"，你可以对其内部的值应用函数。

fmap 接受一个普通函数 a -> b，并将其应用到容器中的值上。

对比 Lisp：mapcar 是 List Functor 的 fmap。

2. List 是 Functor

-- fmap on lists = map
instance Functor [] where
  fmap = map

Prelude> fmap (*2) [1,2,3]
[2,4,6]
Prelude> (*2) <$> [1,2,3]
[2,4,6]
Prelude> fmap even [1,2,3]
[False,True,False]

3. Maybe 是 Functor

instance Functor Maybe where
  fmap _ Nothing  = Nothing
  fmap f (Just x) = Just (f x)

Prelude> fmap (*2) (Just 5)
Just 10
Prelude> fmap (*2) Nothing
Nothing
Prelude> (*2) <$> Just 5
Just 10
Kotlin
maybe?.let { it * 2 }
Haskell
(*2) <$> maybe

4. Either 是 Functor

instance Functor (Either a) where
  fmap _ (Left x)  = Left x    -- 错误路径不动
  fmap f (Right x) = Right (f x)

Prelude> fmap (*2) (Right 5)
Right 10
Prelude> fmap (*2) (Left "error")
Left "error"

5. IO 也是 Functor

instance Functor IO where
  fmap f action = do
    x <- action
    return (f x)

-- 实用示例：处理用户输入
main :: IO ()
main = do
  -- 不用 fmap
  input <- getLine
  let upper = map toUpper input
  putStrLn upper

  -- 用 fmap（更简洁）
  upper <- map toUpper <$> getLine
  putStrLn upper

6. Functor 法则

-- 法则 1：身份
fmap id  =  id
-- 对比：map id [1,2,3] = [1,2,3]

-- 法则 2：组合
fmap (f . g)  =  fmap f . fmap g
-- 对比：map (f . g) = map f . map g
理解：Functor 法则确保 fmap 只映射内部的值，不会改变容器的结构。

小结

  • Functor = 可映射的容器/上下文
  • fmap :: (a -> b) -> f a -> f b 或 <$>
  • List、Maybe、Either、IO 都是 Functor
  • Functor 法则保证结构不变
