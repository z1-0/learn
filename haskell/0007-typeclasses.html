第七课：类型类基础

课程编号: 0007 | 前置知识: 第二课（类型签名） | 预计时间: 35-40 分钟

类型类是 Haskell 实现多态的方式。它们类似于其他语言的接口或 trait，但更强大。

1. 什么是类型类？

类型类定义了一组函数（方法），任何类型如果希望支持这些操作，就可以"实例化"这个类型类。

-- 类型类定义
class Eq a where
  (==) :: a -> a -> Bool
  (/=) :: a -> a -> Bool

-- 实例化 Bool 类型
instance Eq Bool where
  True  == True  = True
  False == False = True
  _     == _     = False

  x /= y = not (x == y)
Java
interface Eq<T> {
boolean eq(T a, T b);
}
TypeScript
interface Eq<T> {
equals(a: T, b: T): boolean
}
Haskell
class Eq a where
(==) :: a -> a -> Bool

3. deriving：自动派生

Haskell 可以自动为你生成类型类实例：

data Color = Red | Green | Blue
  deriving (Show, Eq, Ord)

-- 现在可以直接使用
Prelude> show Red
"Red"
Prelude> Red == Green
False
Prelude> Red < Green
True
Kotlin 用户注意：类似 data class 自动生成 toString、equals、hashCode。

4. 类型约束 (Constraints)

在类型签名中使用 => 来约束类型参数：

-- Eq a => 表示 a 必须是 Eq 的实例
elem :: Eq a => a -> [a] -> Bool
elem _ []     = False
elem x (y:ys) = x == y || elem x ys

-- Ord a => 表示 a 必须是 Ord 的实例
sort' :: Ord a => [a] -> [a]

-- 多个约束
foo :: (Eq a, Show a, Num a) => a -> String
foo x = if x == 0 then "zero" else show x
概念：=> 的含义

类型签名 elem :: Eq a => a -> [a] -> Bool 读作：

"对于任何满足 Eq 的类型 a，elem 接受一个 a 和一个 [a]，返回 Bool"

对比 TypeScript：function elem<T extends Eq<T>>(x: T, list: T[]): boolean

5. 自定义类型类

-- 定义自己的类型类
class Describable a where
  describe :: a -> String

-- 为 Person 实现
data Person = Person { name :: String, age :: Int }

instance Describable Person where
  describe (Person n a) = n ++ " (" ++ show a ++ " years old)"

-- 为 Int 实现
instance Describable Int where
  describe x = "The number " ++ show x
