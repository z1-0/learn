第十课：Maybe 与错误处理

课程编号: 0010 | 前置知识: 第七课（类型类）、第九课（IO） | 预计时间: 35-40 分钟

Haskell 没有 null 引用。它用 Maybe 和 Either 类型来安全地处理缺失值和错误。

1. Maybe 类型

-- Maybe 的定义
data Maybe a = Nothing | Just a

-- 使用场景：可能失败的操作
headMaybe :: [a] -> Maybe a
headMaybe []    = Nothing
headMaybe (x:_) = Just x

safeDiv :: Double -> Double -> Maybe Double
safeDiv _ 0 = Nothing
safeDiv x y = Just (x / y)
Kotlin
val x: Int? = null
TypeScript
const x: number | undefined
Java
Optional<Integer> x
Haskell
x :: Maybe Int
x = Nothing

2. 使用 Maybe 值

-- 模式匹配
case safeDiv 10 2 of
  Nothing -> putStrLn "Division failed!"
  Just v  -> putStrLn ("Result: " ++ show v)

-- 在函数中处理 Maybe
addMaybe :: Maybe Int -> Maybe Int -> Maybe Int
addMaybe (Just x) (Just y) = Just (x + y)
addMaybe _        _        = Nothing

-- Data.Maybe 工具函数
import Data.Maybe

fromMaybe :: a -> Maybe a -> a    -- 提供默认值
fromMaybe 0 Nothing   -- 0
fromMaybe 0 (Just 5)  -- 5

isJust :: Maybe a -> Bool
isNothing :: Maybe a -> Bool
catMaybes :: [Maybe a] -> [a]     -- 过滤出所有 Just
mapMaybe :: (a -> Maybe b) -> [a] -> [b]

3. Either 类型

-- Either 的定义（标准库）
data Either a b = Left a | Right b

-- Left 通常表示错误，Right 表示成功
safeDiv' :: Double -> Double -> Either String Double
safeDiv' _ 0 = Left "Division by zero!"
safeDiv' x y = Right (x / y)

-- 使用 Either
case safeDiv' 10 0 of
  Left err -> putStrLn ("Error: " ++ err)
  Right v  -> putStrLn ("Result: " ++ show v)
概念：Maybe vs Either

Maybe：只有"无值"信息

Either：携带错误信息

类型惯例：Either String a 或 Either ErrorType a

4. 链式处理

-- 不使用 Maybe 的链式调用（嵌套 case）
process :: String -> Maybe Int
process s = case readMaybe s of
  Nothing -> Nothing
  Just n  -> case safeDiv 100 n of
    Nothing -> Nothing
    Just v  -> Just (v * 2)

-- 使用 Maybe 的 Monad 特性（下节课会学到）
process' :: String -> Maybe Int
process' s = do
  n <- readMaybe s
  v <- safeDiv 100 n
  return (v * 2)

5. 实际例子：安全查找

-- 安全数据库查找
type UserId = Int
data User = User { userName :: String, userAge :: Int }

users :: [(UserId, User)]
users = [(1, User "Alice" 28), (2, User "Bob" 35)]

findUser :: UserId -> Maybe User
findUser id = lookup id users

greetUser :: UserId -> IO ()
greetUser id = case findUser id of
  Nothing -> putStrLn "User not found!"
  Just u  -> putStrLn ("Hello, " ++ userName u ++ "!")

小结

  • Maybe a = Nothing | Just a，无 null 的安全方案
  • Either e a = Left e | Right a，携带错误信息
  • 模式匹配是处理 Maybe/Either 的基本方式
  • Data.Maybe 提供实用工具函数
  • 编译器强制你处理所有情况，无空指针异常
