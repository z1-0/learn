第二十四课：并发与并行

课程编号: 0024 | 前置知识: 第十三课（Monad）、第十七课（IO） | 预计时间: 35-40 分钟

Haskell 提供了多种并发和并行机制：轻量级线程（forkIO）、软件事务内存（STM）、以及并行策略（Par）。

1. forkIO：轻量级线程

import Control.Concurrent
import Control.Concurrent.Chan

-- forkIO 创建轻量级线程
main :: IO ()
main = do
  putStrLn "Starting threads..."
  forkIO $ do
    threadDelay 1000000  -- 1 秒
    putStrLn "Thread 1 done"
  forkIO $ do
    threadDelay 2000000
    putStrLn "Thread 2 done"
  threadDelay 3000000
  putStrLn "Main done"

-- MVar：线程间通信（一个槽位）
main' :: IO ()
main' = do
  mvar <- newEmptyMVar
  forkIO $ do
    putMVar mvar "Hello from thread"
  msg <- takeMVar mvar
  putStrLn msg

2. Channel：多对多通信

import Control.Concurrent.Chan

main :: IO ()
main = do
  chan <- newChan

  -- 生产者
  forkIO $ do
    mapM_ (writeChan chan) [1..10]
    putStrLn "Producer done"

  -- 消费者
  forkIO $ do
    replicateM_ 10 $ do
      msg <- readChan chan
      putStrLn ("Got: " ++ show msg)

  threadDelay 1000000

3. STM：软件事务内存

import Control.Concurrent.STM
import Control.Concurrent.STM.TVar

-- STM 类似数据库事务
-- 原子性：要么全成功，要么全回滚
-- 隔离性：事务之间互不干扰

main :: IO ()
main = do
  counter <- newTVarIO 0

  -- 多个线程同时修改
  forkIO $ replicateM_ 1000 $
    atomically $ modifyTVar' counter (+1)

  forkIO $ replicateM_ 1000 $
    atomically $ modifyTVar' counter (+1)

  threadDelay 1000000

  result <- readTVarIO counter
  putStrLn ("Counter: " ++ show result)
  -- 总是 2000！
概念：STM vs MVar

MVar：线程阻塞等待，容易死锁

STM：乐观并发，事务冲突时自动重试

推荐在复杂并发场景使用 STM

4. 并发下载器

import Control.Concurrent
import Control.Concurrent.Async
import Network.HTTP.Simple

-- 最简单的并发方式：async
main :: IO ()
main = do
  -- async 并发执行，返回 Async 句柄
  a1 <- async (httpLBS "http://example.com")
  a2 <- async (httpLBS "http://haskell.org")

  -- wait 等待结果
  r1 <- wait a1
  r2 <- wait a2

  putStrLn ("Example: " ++ show (getResponseStatus r1))
  putStrLn ("Haskell: " ++ show (getResponseStatus r2))

-- 并发映射
concurrentMap :: (a -> IO b) -> [a] -> IO [b]
concurrentMap f xs = do
  asyncs <- mapM (async . f) xs
  mapM wait asyncs

5. 并行策略（Par）

import Control.Parallel.Strategies

-- parallel：纯计算的并行

-- 普通计算
sumSquares :: [Int] -> Int
sumSquares xs = sum (map (^2) xs)

-- 并行计算
sumSquaresPar :: [Int] -> Int
sumSquaresPar xs = sum (map (^2) xs `using` parList rseq)

-- 策略说明
-- rseq   : 求值为弱头范式
-- rdeepseq : 完全求值
-- parList : 列表并行
-- parMap  : 并行 map

-- 使用
main :: IO ()
main = do
  let result = sumSquaresPar [1..1000000]
  print result

-- 需要编译：ghc -O2 -threaded Main.hs
-- 运行：./Main +RTS -N4 （使用 4 核）

场景工具说明
纯计算加速Strategies并行策略，自动划分
IO 并发任务async最简单的并发 IO

小结

  • forkIO 创建轻量级线程
  • async 简化并发 IO 管理
  • STM 提供安全的事务内存
  • Strategies 实现纯计算并行
  • 编译时需要 -threaded 标志
