第九课：IO 与 do 记法

课程编号: 0009 | 前置知识: 第三课（函数定义） | 预计时间: 40-45 分钟

IO 是 Haskell 中处理副作用的方式。与 Java 或 Python 不同，Haskell 用类型系统将纯代码与不纯代码严格分离。

1. 纯函数 vs 不纯函数

-- 纯函数：相同输入 → 相同输出
add :: Int -> Int -> Int
add x y = x + y

-- 不纯函数：返回值依赖外部世界
getLine :: IO String           -- 读取一行输入
putStrLn :: String -> IO ()    -- 输出一行

-- main 是程序的入口
main :: IO ()
main = putStrLn "Hello, World!"
概念：IO 类型

IO a 表示"一个可能包含副作用的计算，执行后返回 a 类型的值"。

IO () 类似 Java 的 void——执行操作但不返回有意义的值。

2. do 记法

-- do 记法让你按顺序书写 IO 操作
main :: IO ()
main = do
  putStrLn "What is your name?"
  name <- getLine               -- 从 IO 中取出 String
  putStrLn ("Hello, " ++ name ++ "!")
  putStrLn "Nice to meet you."

-- 不使用 <- 会丢弃返回值
main = do
  putStrLn "Line 1"
  putStrLn "Line 2"
Kotlin
println("What is your name?")
val name = readLine()
println("Hello, $name!")
Haskell
do
putStrLn "What is your name?"
name <- getLine
putStrLn ("Hello, " ++ name ++ "!")

3. let 在 do 中

main :: IO ()
main = do
  putStrLn "Enter a number:"
  input <- getLine
  let num = read input :: Int    -- 纯计算，用 let
      doubled = num * 2
  putStrLn ("Double is: " ++ show doubled)
关键区分：<- vs let

<- 从 IO 操作中提取值（有副作用）

let 定义纯表达式（无副作用）

在 do 中，let 不需要 in。

4. return 不是你想的那样

-- return 不是"返回"，而是"包装"
-- 它把一个纯值放入 IO 中
main :: IO ()
main = do
  let x = 42              -- x :: Int
  y <- return x           -- y :: Int（从 IO Int 中取出）
  print y

-- return 的等价写法：
return42 :: IO Int
return42 = return 42

-- 相当于：把纯值"提升"到 IO 中
注意：return 不是控制流关键字！它是一个普通函数，把纯值包装到 IO 中。

5. 常用 IO 函数

putStrLn :: String -> IO ()     -- 输出一行
print    :: Show a => a -> IO () -- 输出任意可 show 的值
getLine  :: IO String           -- 读取一行
getChar  :: IO Char             -- 读取一个字符
readFile :: FilePath -> IO String   -- 读取文件
writeFile :: FilePath -> String -> IO () -- 写入文件
interact :: (String -> String) -> IO () -- 读取全部输入，处理，输出

6. 简单例子：交互式程序

main :: IO ()
main = do
  putStrLn "Welcome to the Haskell calculator!"
  putStrLn "Enter two numbers:"
  a <- readLn :: IO Double
  b <- readLn :: IO Double
  putStrLn ("Sum: " ++ show (a + b))
  putStrLn ("Product: " ++ show (a * b))

练习 2

写一个程序：不断读取用户输入，直到用户输入"quit"。

main :: IO ()
main = do
  line <- getLine
  if line == "quit"
    then return ()
    else do
      putStrLn ("You said: " ++ line)
      main

用 interact 写一个程序，将输入全部转为大写。

小结

  • IO a 表示带副作用的计算
  • do 记法按顺序组合 IO 操作
  • <- 提取值，let 纯定义
  • return 包装值到 IO，不是控制流
  • 纯函数和 IO 函数严格分离
