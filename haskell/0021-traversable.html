第二十一课：Traversable 与遍历

课程编号: 0021 | 前置知识: 第十二课（Applicative）、第十四课（Foldable） | 预计时间: 35-40 分钟

Traversable 是 Functor 和 Foldable 的结合。它让你遍历一个数据结构，在每个元素上执行一个 Effectful 的计算，然后重新组合结果。

1. Traversable 定义

class (Functor t, Foldable t) => Traversable t where
  traverse :: Applicative f => (a -> f b) -> t a -> f (t b)
  sequenceA :: Applicative f => t (f a) -> f (t a)

-- traverse：对每个元素应用函数（返回 Applicative），然后重组
-- sequenceA：将嵌套的 Applicative 翻转

2. 直观理解

-- Functor:      fmap  :: (a -> b) -> t a -> t b
--               纯函数，应用到容器内每个元素

-- Foldable:     foldMap :: (a -> m) -> t a -> m
--               合并所有元素为一个值

-- Traversable:  traverse :: (a -> f b) -> t a -> f (t b)
--               带效果的函数，应用到每个元素并重组

-- 通俗理解：
-- "遍历列表，对每个元素执行 IO 操作，收集结果"
-- "遍历 Maybe，如果值是 Just x，应用函数，否则保持 Nothing"

3. List 的 Traversable 实例

-- 对列表中的每个元素执行 IO
Prelude> traverse print [1,2,3]
1
2
3
[(),(),()]

-- 对 Maybe 列表处理
Prelude> traverse id [Just 1, Just 2, Just 3]
Just [1,2,3]

Prelude> traverse id [Just 1, Nothing, Just 3]
Nothing

-- sequenceA：调换顺序
Prelude> sequenceA [Just 1, Just 2, Just 3]
Just [1,2,3]

Prelude> sequenceA [print 1, print 2, print 3]
1
2
3
[(),(),()]

4. SequenceA 的作用

-- sequenceA：将 [IO a] 转为 IO [a]
-- 从"多个独立 IO 操作"到"一个 IO 操作返回列表"

readThreeLines :: IO [String]
readThreeLines = sequenceA [getLine, getLine, getLine]

-- 等价于：
readThreeLines' :: IO [String]
readThreeLines' = do
  a <- getLine
  b <- getLine
  c <- getLine
  return [a, b, c]

-- 对于 Maybe：
Prelude> sequenceA [Just 1, Just 2]
Just [1,2]
Prelude> sequenceA [Just 1, Nothing]
Nothing

5. 实际例子：遍历树

data Tree a = Leaf a | Node (Tree a) (Tree a)
  deriving (Show, Functor, Foldable, Traversable)

-- GHC 可以自动派生 Traversable！

-- 树中所有值加 1（用 Functor）
fmap (+1) tree

-- 求和（用 Foldable）
foldl (+) 0 tree

-- 对每个值打印（用 Traversable）
traverse print tree

-- 如果树中有 Maybe 值，展开它们
sequenceA (Node (Leaf (Just 1)) (Leaf Nothing))
-- Nothing

sequenceA (Node (Leaf (Just 1)) (Leaf (Just 2)))
-- Just (Node (Leaf 1) (Leaf 2))

6. mapM：Traversable 的特化

-- mapM 是 traverse 针对 Monad 的特化（历史原因）
mapM :: (Traversable t, Monad m) => (a -> m b) -> t a -> m (t b)

-- traverse 更通用（只需要 Applicative）
traverse :: (Traversable t, Applicative f) => (a -> f b) -> t a -> f (t b)

-- 实际上，traverse 和 mapM 功能相同
-- 现在推荐用 traverse

Prelude> mapM print [1,2,3]
1
2
3
[(),(),()]

Prelude> mapM readLn [1..3] :: IO [Int]
-- 等待 3 次输入

7. Traversable 法则

-- 自然性
traverse Identity = Identity

-- 组合
traverse (Compose . fmap g . f) = Compose . fmap (traverse g) . traverse f

-- 实际理解：
-- traverse 保持数据结构形状不变
-- 只是改变内部的值

小结

  • Traversable = Functor + Foldable + 效果遍历
  • traverse :: (a -> f b) -> t a -> f (t b)
  • sequenceA 翻转嵌套的效果
  • 可以自动派生 Traversable
  • 适合遍历数据结构并执行带效果的操作
