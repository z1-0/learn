第一课：GHCi 入门

课程编号: 0001 | 前置知识: 基本编程经验 | 预计时间: 15-20 分钟

你已经会多种编程语言，现在要学 Haskell。好消息是：你不需要从零开始。这节课带你用 GHCi（Haskell 的交互式环境）快速上手，感受 Haskell 与其他语言的核心差异。

1. 启动 GHCi

在终端输入：

ghci

你会看到类似这样的提示符：

GHCi, version 9.10.3: https://www.haskell.org/ghc/  :? for help
Prelude>

Prelude 是 Haskell 的标准库模块名。看到这个提示符，说明 GHCi 已就绪。

提示：在 GHCi 中输入 :quit 或 :q 可以退出。

2. 基本运算

直接输入表达式，GHCi 会求值并输出结果：

Prelude> 2 + 3
5
Prelude> 10 * 5
50
Prelude> 2 ^ 100
1267650600228229401496703205376
概念：一切皆表达式

在 Haskell 中，没有"语句"这个概念。每一行都是一个表达式，都有返回值。

对比 Nix：你已经熟悉这个概念了！Nix 也是一切皆表达式。

对比 Java/Kotlin/JS：你习惯了 if 是语句，但在 Haskell 中 if 是表达式。

3. 布尔值与比较

Prelude> True && False
False
Prelude> 3 > 2
True
Prelude> "hello" == "hello"
True
Kotlin
val result = 3 > 2 // true
Nix
3 > 2 # true
Haskell
3 > 2 -- True

4. 字符串

Prelude> "Hello" ++ " World"
"Hello World"
Prelude> length "Hello"
5
Prelude> head "Hello"
'H'

++ 是连接运算符（类似 Kotlin 的 +）。

注意：单引号 'H' 是字符（Char），双引号 "Hello" 是字符串（String）。

5. 列表

列表是 Haskell 最重要的数据结构：

Prelude> [1, 2, 3]
[1,2,3]
Prelude> 1 : [2, 3]
[1,2,3]
Prelude> [1, 2] ++ [3, 4]
[1,2,3,4]
概念：: 操作符

: 将一个元素添加到列表头部（类似 Kotlin 的 listOf(1) + listOf(2, 3)，但更高效）。

这叫"cons"操作。在 Lisp 中，(cons 1 '(2 3)) 做同样的事情。

6. 列表范围

Prelude> [1..5]
[1,2,3,4,5]
Prelude> [1,3..10]
[1,3,5,7,9]
Prelude> ['a'..'e']
"abcde"
Dart
List.generate(5, (i) => i + 1)
Nix
builtins.genList (x: x + 1) 5
Haskell
[1..5]

7. 函数调用

Haskell 函数调用不需要括号，用空格分隔参数：

Prelude> div 10 3
3
Prelude> mod 10 3
1
Prelude> take 3 [1, 2, 3, 4, 5]
[1,2,3]
概念：中缀 vs 前缀

函数默认是前缀调用（在参数前面）。但可以用反引号变成中缀：

Prelude> 10 `div` 3
3

类似 Kotlin 的 infix 函数。

8. 定义函数

在 GHCi 中用 let 定义函数：

Prelude> let double x = x * 2
Prelude> double 5
10
Prelude> let add a b = a + b
Prelude> add 3 4
7
JavaScript
const double = x => x * 2;
Nix
double = x: x * 2;
Lisp
(defun double (x) (* x 2))
Haskell
double x = x * 2
注意：Haskell 中 = 不是赋值，而是定义（类似数学等式）。一旦定义，值不可变。

9. 条件表达式

Prelude> let absValue x = if x >= 0 then x else -x
Prelude> absValue (-5)
5
Prelude> absValue 3
3

if...then...else 在 Haskell 中是表达式（必须有 else），不是语句。

Kotlin
val abs = if (x >= 0) x else -x
Nix
if x >= 0 then x else -x
Lisp
(if (>= x 0) x (- x))
Haskell
if x >= 0 then x else -x

10. 看类型

用 :t 查看表达式的类型：

Prelude> :t True
True :: Bool
Prelude> :t 42
42 :: Num p => p
Prelude> :t "hello"
"hello" :: [Char]
Prelude> :t length
length :: Foldable t => t a -> Int
概念：类型签名中的 =>

Num p => p 表示 p 必须是 Num 类型类的实例。

这类似 TypeScript 的泛型约束：function identity<T extends Number>(x: T): T

Lisp 没有这个概念（动态类型）。Nix 也没有（动态类型）。Haskell 的静态类型系统是它最大的优势之一。

练习

练习 1

在 GHCi 中计算 (2 + 3) * 4。结果是多少？

练习 2

用 :t 查看 (++) 的类型。它接受什么参数？返回什么？

练习 3

定义一个函数 square x = x * x，然后计算 square 5。

练习 4

用 take 和 drop 从 [1..10] 中取出 [4,5,6]。

小结

你已经学会了：

  • 启动和使用 GHCi
  • Haskell 中一切皆表达式
  • 基本运算、字符串、列表操作
  • 函数定义（= 是定义，不是赋值）
  • 用 :t 查看类型
关键思维转变

Haskell 的核心理念：用数学等式描述"是什么"，而不是告诉计算机"怎么做"。

如果你用过 Nix，你已经熟悉这个理念了！Nix 的 let...in、模式匹配、不可变绑定，都是函数式编程的核心概念。

这与你在 Java/Kotlin/JS 中的习惯不同，但一旦适应，你会发现代码更简洁、更可靠。
