第五课：高阶函数

课程编号: 0005 | 前置知识: 第四课（列表与递归） | 预计时间: 35-40 分钟

高阶函数是接受函数作为参数或返回函数的函数。这是函数式编程的核心武器。

1. 什么是高阶函数？

-- 普通函数：接受值
add :: Int -> Int -> Int
add x y = x + y

-- 高阶函数：接受函数
applyTwice :: (a -> a) -> a -> a
applyTwice f x = f (f x)

Prelude> applyTwice (*2) 5
20
Lisp
(defun apply-twice (f x)
(funcall f (funcall f x)))
Haskell
applyTwice f x = f (f x)

2. map

-- map 的类型
map :: (a -> b) -> [a] -> [b]

-- 使用 map
Prelude> map (*2) [1,2,3,4]
[2,4,6,8]
Prelude> map even [1,2,3,4]
[False,True,False,True]
Prelude> map ("Hello " ++) ["Alice","Bob"]
["Hello Alice","Hello Bob"]
JS
[1,2,3].map(x => x * 2)
Lisp
(mapcar (lambda (x) (* x 2)) '(1 2 3))
Haskell
map (*2) [1,2,3]

3. filter

-- filter 的类型
filter :: (a -> Bool) -> [a] -> [a]

-- 使用 filter
Prelude> filter even [1..10]
[2,4,6,8,10]
Prelude> filter (>5) [1..10]
[6,7,8,9,10]
Prelude> filter ('a' `elem`) ["apple","banana","cherry"]
["banana"]
JS
[1..10].filter(x => x % 2 === 0)
Haskell
filter even [1..10]

4. fold（归约）

foldl 从左到右，foldr 从右到左：

-- foldl 的类型
foldl :: (b -> a -> b) -> b -> [a] -> b
--       累加器  元素   初始值  列表   结果

-- 用 foldl 求和
Prelude> foldl (\acc x -> acc + x) 0 [1,2,3]
6

-- 更简洁
Prelude> foldl (+) 0 [1,2,3]
6

-- foldr（从右）
Prelude> foldr (+) 0 [1,2,3]
6
概念：foldl vs foldr
-- foldl: 左结合
foldl (+) 0 [1,2,3] = ((0 + 1) + 2) + 3

-- foldr: 右结合
foldr (+) 0 [1,2,3] = 1 + (2 + (3 + 0))

对比 JS：[1,2,3].reduce((a,x) => a + x, 0)

对比 Lisp：(reduce #'+ '(1 2 3))

5. 用 fold 实现一切

-- 用 foldr 实现 map
map' :: (a -> b) -> [a] -> [b]
map' f = foldr (\x acc -> f x : acc) []

-- 用 foldr 实现 filter
filter' :: (a -> Bool) -> [a] -> [a]
filter' p = foldr (\x acc -> if p x then x : acc else acc) []

-- 用 foldl 实现 reverse
reverse' :: [a] -> [a]
reverse' = foldl (\acc x -> x : acc) []

-- 用 foldl 实现 sum
sum' :: Num a => [a] -> a
sum' = foldl (+) 0

6. Lambda 表达式

-- 无名函数
Prelude> map (\x -> x * 2 + 1) [1..5]
[3,5,7,9,11]

Prelude> filter (\x -> x > 3 && even x) [1..10]
[4,6,8,10]

-- 多参数 lambda
Prelude> foldl (\acc x -> acc ++ [x * 2]) [] [1,2,3]
[2,4,6]
JS
x => x * 2 + 1
Lisp
(lambda (x) (+ (* x 2) 1))
Nix
x: x * 2 + 1
Haskell
\x -> x * 2 + 1

7. 部分应用（柯里化）

-- 所有函数默认柯里化
add :: Int -> Int -> Int
add x y = x + y

-- 部分应用：只传部分参数
add5 :: Int -> Int
add5 = add 5

Prelude> add5 3
8

-- 常见用法
Prelude> map (add 10) [1,2,3]
[11,12,13]
Prelude> filter (>10) [5,12,3,15]
[12,15]
Prelude> map (++ "!!!") ["hi","bye"]
["hi!!!","bye!!!"]
概念：柯里化 = 偏函数自动

add 5 返回一个函数 (Int -> Int)，因为 add :: Int -> Int -> Int 实际上是 Int -> (Int -> Int)。

对比 Nix：add = x: y: x + y; add 5 也返回一个函数。

8. 函数组合 (.)

-- 组合两个函数
(.) :: (b -> c) -> (a -> b) -> a -> c
-- f . g = \x -> f (g x)

-- 不用组合
Prelude> map (\x -> negate (abs x)) [5, -3, -8, 2]
[-5,-3,-8,-2]

-- 用组合
Prelude> map (negate . abs) [5, -3, -8, 2]
[-5,-3,-8,-2]

-- pipe 风格
Prelude> map (reverse . filter even . map (*2)) [[1,2],[3,4],[5,6]]
[[4],[8],[12]]
概念：组合 = pipe

f . g 表示"先做 g，再做 f"。

类似 Nix 的 builtins.pipe，但更简洁。

练习

练习 1

用 map 将字符串列表转大写。

提示：用 Data.Char.toUpper

练习 2

用 filter 找出 1 到 50 中所有平方数。

提示：floor (sqrt x) 的平方等于 x

练习 3

用 foldl 计算一个列表的最大值。

练习 4

用函数组合实现：先取偶数，再乘 2，再反转。

签名：process :: [Int] -> [Int]

小结

你已经学会了：

  • map - 变换每个元素
  • filter - 筛选元素
  • foldl / foldr - 归约列表
  • Lambda（\x -> ...）
  • 部分应用（柯里化）
  • 函数组合（.）
关键要点

高阶函数让你声明式地处理数据，而不是手写递归循环。

对比 JS：arr.map(f).filter(g).reduce(h) 和 Haskell 的 foldr h (filter g (map f arr)) 是同一概念。
