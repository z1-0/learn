第三课：函数定义与模式匹配

课程编号: 0003 | 前置知识: 第一课、第二课 | 预计时间: 35-40 分钟

函数是 Haskell 的核心。这节课你将学会如何定义函数，以及 Haskell 最强大的特性之一——模式匹配。

1. 函数定义基础

-- 最简单的函数
double :: Int -> Int
double x = x * 2

-- 多参数函数（柯里化）
add :: Int -> Int -> Int
add x y = x + y

-- 不需要参数
greet :: String -> String
greet name = "Hello, " ++ name ++ "!"
Nix
double = x: x * 2;
add = x: y: x + y;
Lisp
(defun double (x) (* x 2))
(defun add (x y) (+ x y))
Haskell
double x = x * 2
add x y = x + y
概念：柯里化

Haskell 函数默认只接受一个参数。add x y 实际上是 add x 返回一个函数，这个函数再接受 y。

这和 Nix 的 x: y: x + y 完全一样！

2. 模式匹配

模式匹配让你根据输入的结构选择不同的处理方式：

-- 匹配具体值
isZero :: Int -> Bool
isZero 0 = True
isZero _ = False

-- 匹配列表结构
head' :: [a] -> a
head' (x:_) = x
head' []    = error "empty list"
Kotlin
when (x) {
0 -> true
else -> false
}
Nix
if x == 0 then true else false
Lisp
(cond ((= x 0) t)
(t nil))
Haskell
isZero 0 = True
isZero _ = False
概念：通配符 _

_ 匹配任何值但不绑定变量。类似 Kotlin 的 else，Nix 的 _（在模式匹配中），Lisp 的 t。

3. 递归与模式匹配

递归是 Haskell 处理循环的方式：

-- 计算阶乘
factorial :: Integer -> Integer
factorial 0 = 1
factorial n = n * factorial (n - 1)

-- 计算列表长度
length' :: [a] -> Int
length' []     = 0
length' (_:xs) = 1 + length' xs

-- 求和
sum' :: Num a => [a] -> a
sum' []     = 0
sum' (x:xs) = x + sum' xs
概念：基本情形 vs 递归情形

每个递归函数需要：

  • 基本情形：停止条件（如 factorial 0 = 1）
  • 递归情形：分解问题（如 factorial n = n * factorial (n-1)）

对比 Nix：Nix 的递归函数写法类似，但用 let...in。

4. Guard（守卫）

Guard 用竖线 | 根据条件选择分支：

-- 判断正负
sign :: Int -> Int
sign x
  | x > 0    = 1
  | x == 0   = 0
  | otherwise = -1

-- 取最大值
maxOfTwo :: Ord a => a -> a -> a
maxOfTwo x y
  | x > y    = x
  | otherwise = y

-- 成绩等级
grade :: Int -> String
grade score
  | score >= 90 = "A"
  | score >= 80 = "B"
  | score >= 70 = "C"
  | score >= 60 = "D"
  | otherwise   = "F"
概念：otherwise

otherwise 是 True 的别名，表示"其他情况"。类似 Kotlin 的 else。

Kotlin
fun grade(score: Int) = when {
score >= 90 -> "A"
score >= 80 -> "B"
else -> "C"
}
Haskell
grade score
| score >= 90 = "A"
| score >= 80 = "B"
| otherwise = "C"

5. case 表达式

case 是内联的模式匹配：

-- 使用 case
describe :: [a] -> String
describe xs = case xs of
  []  -> "empty list"
  [x] -> "single element"
  _   -> "multiple elements"

-- 在其他表达式中使用
safeHead :: [a] -> Maybe a
safeHead xs = case xs of
  (x:_) -> Just x
  []    -> Nothing
Kotlin
when (list.size) {
0 -> "empty"
1 -> "single"
else -> "multiple"
}
Haskell
case list of
[] -> "empty"
[_] -> "single"
_ -> "multiple"

6. Where 绑定

用 where 复用局部定义：

-- 计算圆的面积
circleArea :: Double -> Double
circleArea r = pi * r * r

-- 使用 where 复用计算
bmi :: Double -> Double -> String
bmi weight height
  | bmi < 18.5 = "偏瘦"
  | bmi < 25.0 = "正常"
  | bmi < 30.0 = "偏胖"
  | otherwise  = "肥胖"
  where bmi = weight / height ^ 2
概念：where vs let

where 在函数体后面定义局部变量。

let...in 在表达式中定义局部变量。

-- let 用法
cylinderVolume r h =
  let area = pi * r * r
  in area * h

7. 组合函数

-- 函数组合
applyTwice :: (a -> a) -> a -> a
applyTwice f x = f (f x)

-- 使用
Prelude> applyTwice (+3) 10
16
Prelude> applyTwice (*2) 5
20
Prelude> applyTwice ("Hello " ++) "World"
"Hello Hello World"
Nix 用户注意：Haskell 的函数组合和 Nix 的管道操作类似，但更强大——你可以组合任意函数。

小结

你已经学会了：

  • 函数定义语法（f x = ...）
  • 模式匹配（case、函数参数模式）
  • Guard（| 守卫条件）
  • Where 绑定（where）
  • 递归思维
关键要点

Haskell 用模式匹配替代了大多数 if-else 语句。这让代码更清晰、更安全。

对比 Nix：Nix 也有模式匹配，但 Haskell 的更强大——它可以匹配嵌套结构。
