第二课：类型与类型签名

课程编号: 0002 | 前置知识: 第一课 | 预计时间: 30-35 分钟

类型系统是 Haskell 最强大的特性之一。它能在编译时捕获大量错误，让你对代码更有信心。这节课你将学会阅读和编写类型签名。

1. Haskell 的基本类型

类型说明示例
Bool布尔值True, False
Char单个字符'a', 'Z', '1'
Int固定精度整数（64位）42, -7
Integer任意精度整数2^100
Double双精度浮点数3.14
String字符串"hello"
()单元类型（void）()
Prelude> :t True
True :: Bool
Prelude> :t 'a'
'a' :: Char
Prelude> :t 42
42 :: Num p => p
Prelude> :t 3.14
3.14 :: Fractional p => p
Prelude> :t "hello"
"hello" :: [Char]
概念：字符串是字符列表

Haskell 中 String 就是 [Char]（字符的列表）。

对比 Nix：Nix 中字符串是基本类型，但在 Haskell 中它是语法糖。

2. 类型签名

类型签名写在函数定义的上方，用 :: 连接：

-- 类型签名（可选，但强烈推荐）
add :: Int -> Int -> Int
-- 函数定义
add x y = x + y
TypeScript
function add(x: number, y: number): number
Nix
add = x: y: x + y;
Lisp
(defun add (x y) (+ x y))
Haskell
add :: Int -> Int -> Int
概念：箭头 -> 表示函数

Int -> Int -> Int 表示：接受两个 Int，返回一个 Int。

箭头从左到右：参数1 → 参数2 → 返回值。

3. 类型推断

Haskell 可以自动推断类型，你不需要处处写类型签名：

-- 不写类型签名，Haskell 会推断
add x y = x + y

-- 用 :t 看推断结果
Prelude> :t add
add :: Num a => a -> a -> a

但推荐写类型签名，因为：

  • 帮助你理解代码意图
  • 编译器会检查你的实现是否匹配签名
  • 文档化函数的接口
最佳实践：永远给函数写类型签名。这是 Haskell 社区的惯例。

4. 多态类型

类型变量用小写字母表示，表示"任意类型"：

-- identity 可以接受任意类型
identity :: a -> a
identity x = x

-- 第一个元素
head :: [a] -> a
head (x:_) = x

-- 比较两个值
eq :: Eq a => a -> a -> Bool
eq x y = x == y
TypeScript
function identity<T>(x: T): T
Haskell
identity :: a -> a
概念：约束 =>

Eq a => a -> a -> Bool 中的 Eq a => 表示类型 a 必须支持相等比较。

这类似 TypeScript 的 <T extends Equatable>。

5. 常见类型类

类型类说明实例
Eq可比较相等Bool, Int, String, Char
Ord可排序Bool, Int, Char, String
Show可转为字符串所有标准类型
Read可从字符串解析所有标准类型
Num数值类型Int, Integer, Double
Integral整数类型Int, Integer
Floating浮点类型Double, Float

(==) :: Eq a => a -> a -> Bool

Prelude> :t (+)

6. 类型 vs 类型类

重要区分

类型（Type）：具体的值分类，如 Int、Bool、String。

类型类（Type Class）：行为的接口，如 Eq、Show、Num。

对比 Java：类型 ≈ 类，类型类 ≈ 接口。

对比 Nix：Nix 没有类型类的概念（动态类型）。

7. 函数类型

函数本身也有类型！

-- add 的类型
Prelude> :t add
add :: Num a => a -> a -> a

-- map 的类型
Prelude> :t map
map :: (a -> b) -> [a] -> [b]

-- filter 的类型
Prelude> :t filter
filter :: (a -> Bool) -> [a] -> [a]
概念：函数作为参数

(a -> b) 表示一个函数作为参数。括号是必须的。

对比 Lisp：(mapcar f list) 中 f 也是函数参数。

8. 组合类型

-- 列表类型
Prelude> :t [1, 2, 3]
[1, 2, 3] :: Num a => [a]

-- Maybe 类型（可能有值，可能没有）
Prelude> :t Just 42
Just 42 :: Num a => Maybe a
Prelude> :t Nothing
Nothing :: Maybe a

-- Either 类型（两种可能）
Prelude> :t Left "error"
Left "error" :: Either String b
Prelude> :t Right 42
Right 42 :: Num a => Either b a
Kotlin
val x: Int? = null // Maybe Int
Haskell
Nothing :: Maybe Int
Nix 用户注意：Haskell 的 Maybe 类似 Nix 的 or 机制，但更安全——编译器强制你处理 Nothing 的情况。

小结

你已经学会了：

  • Haskell 的基本类型（Bool, Char, Int, String 等）
  • 类型签名语法（:: 和 ->）
  • 类型推断（Haskell 自动推断类型）
  • 多态类型（类型变量 a, b）
  • 类型类（Eq, Show, Num 等）
  • 类型 vs 类型类的区别
关键要点

Haskell 的类型系统是你的朋友——它在编译时捕获错误，让你对代码更有信心。

与 Nix 的对比：Nix 是动态类型，类型错误在运行时才发现。Haskell 在编译时就告诉你。
