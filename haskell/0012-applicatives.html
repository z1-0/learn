第十二课：应用函子 Applicative

课程编号: 0012 | 前置知识: 第十一课（Functor） | 预计时间: 35-40 分钟

Applicative 是 Functor 的升级版。Functor 让你将普通函数应用到包装好的值上，而 Applicative 让你将包装好的函数应用到包装好的值上。

1. 问题：Functor 的局限

-- Functor 只能处理单参数函数
(*2) <$> Just 5    -- Just 10

-- 多参数函数呢？
(+) <$> Just 5     -- 结果是 Just (5+) :: Maybe (Int -> Int)
-- 我们得到了一个包装在 Maybe 中的函数！
-- 怎么把这个函数应用到另一个 Maybe 值上？

2. Applicative 定义

class Functor f => Applicative f where
  pure  :: a -> f a           -- 将值放入默认上下文
  (<*>) :: f (a -> b) -> f a -> f b  -- 应用包装的函数

-- 解决上面的问题：
(+) <$> Just 5 <*> Just 3     -- Just 8

-- 拆解：
-- 1. (+) <$> Just 5  => Just (5+)
-- 2. Just (5+) <*> Just 3 => Just 8
概念：<$> 和 <*>

f <$> x <*> y <*> z 模式：

将普通函数 f 应用到包装好的值 x、y、z 上。

就像"提升了"的普通函数调用：f x y z → f <$> x <*> y <*> z

3. Maybe 的 Applicative 实例

instance Applicative Maybe where
  pure = Just

  Nothing <*> _ = Nothing
  _ <*> Nothing = Nothing
  Just f  <*> Just x = Just (f x)

Prelude> pure 5 :: Maybe Int
Just 5

Prelude> (+) <$> Just 3 <*> Just 4
Just 7

Prelude> (+) <$> Just 3 <*> Nothing
Nothing

4. List 的 Applicative 实例

instance Applicative [] where
  pure x = [x]       -- 单元素列表
  fs <*> xs = [f x | f <- fs, x <- xs]  -- 所有组合

Prelude> (*) <$> [1,2] <*> [3,4]
[3,4,6,8]
-- 等价于 [(1*3),(1*4),(2*3),(2*4)]

Prelude> [(+1), (*2)] <*> [1,2,3]
[2,3,4,2,4,6]

5. IO 的 Applicative 实例

-- IO 是 Applicative！
greet :: IO String
greet = (++) <$> getLine <*> getLine

-- 等价于：
greet' :: IO String
greet' = do
  a <- getLine
  b <- getLine
  return (a ++ b)

-- 实际使用
main :: IO ()
main = do
  result <- (++) <$> getLine <*> getLine
  putStrLn result

6. Applicative 工具函数

-- liftA2：将二元函数提升到 Applicative
liftA2 :: (a -> b -> c) -> f a -> f b -> f c
liftA2 f x y = f <$> x <*> y

Prelude> liftA2 (+) (Just 3) (Just 4)
Just 7

-- sequenceA：翻转列表
sequenceA :: (Applicative f) => [f a] -> f [a]
Prelude> sequenceA [Just 1, Just 2, Just 3]
Just [1,2,3]
Prelude> sequenceA [Just 1, Nothing, Just 3]
Nothing

7. Applicative 法则

-- 身份
pure id <*> v = v

-- 组合
pure (.) <*> u <*> v <*> w = u <*> (v <*> w)

-- 同态
pure f <*> pure x = pure (f x)

-- 交换
f <*> pure x = pure ($ x) <*> f
实用理解：不需要记法则。核心模式就是 f <$> x <*> y <*> z。

小结

  • Applicative = Functor + pure + <*>
  • 模式：f <$> x <*> y <*> z
  • pure 将值放入默认上下文
  • <*> 应用包装好的函数
  • Maybe、List、IO 都是 Applicative
