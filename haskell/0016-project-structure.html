第十六课：项目结构与构建

课程编号: 0016 | 前置知识: 第八课（模块系统） | 预计时间: 30-35 分钟

现在你已经学会了 Haskell 语言本身，是时候创建一个真正的项目了。Haskell 有多个构建工具，Cabal 是最常用的之一。

1. 使用 Cabal 创建项目

# 创建新项目
cabal init -n MyProject

# 这会生成：
# MyProject/
#   app/
#     Main.hs
#   MyProject.cabal
#   CHANGELOG.md

# 构建
cabal build

# 运行
cabal run

# REPL（加载项目模块）
cabal repl

2. .cabal 文件结构

cabal-version:      3.0
name:               myproject
version:            0.1.0.0

-- 可执行程序
executable myproject
  main-is:          Main.hs
  build-depends:    base ^>=4.18
  hs-source-dirs:   app
  default-language: Haskell2010

-- 库模块
library
  exposed-modules:  MyLib
  build-depends:    base ^>=4.18
  hs-source-dirs:   src
  default-language: Haskell2010

3. 项目结构推荐

my-project/
  app/
    Main.hs           -- 入口文件
  src/
    Lib.hs            -- 库代码
    Utils/
      String.hs       -- module Utils.String
      File.hs         -- module Utils.File
    Data/
      Types.hs        -- module Data.Types
  test/
    Spec.hs           -- 测试入口
    LibSpec.hs        -- 测试用例
  my-project.cabal    -- 项目配置文件
  CHANGELOG.md
  README.md

4. 依赖管理

-- cabal 文件中声明依赖
build-depends:
    base >=4.14 && <5
  , text ^>=2.0
  , bytestring ^>=0.11
  , containers ^>=0.6
  , aeson ^>=2.1          -- JSON 处理

-- 版本约束符
-- >=4.14    : 版本 >= 4.14
-- <5        : 版本 < 5
-- ^>=2.0    : 版本 >= 2.0 且 < 2.1

# 搜索包
cabal search json

# 更新包索引
cabal update

5. GHC 编译基础

# 直接编译（不通过 cabal）
ghc -o myprogram Main.hs

# 编译并优化
ghc -O2 -o myprogram Main.hs

# GHCi 中加载模块
Prelude> :load Main.hs

# 查看类型
Prelude> :type map

# 查看信息
Prelude> :info Maybe

6. Stack vs Cabal

特性CabalStack
包来源HackageStackage（精选包集）
GHC 管理不管理（需 ghcup）自动管理 GHC 版本
锁定文件cabal.project.freezestack.yaml + stack.lock
新手友好中等更高

小结

  • cabal init 创建项目骨架
  • .cabal 文件描述项目元数据和依赖
  • 标准结构：app/ + src/ + test/
  • cabal build 构建，cabal repl 交互
  • build-depends 管理外部依赖
