  1. 打板（涨停）家族是唯一的短线候选 alpha，但存在「买不进」执行折价：board_hold / first_board（夏普 1.89）、dragon_head（1.88）、board_1d（1.85），年化 68-80%。涨停是唯一有效的事前信号；涨 3-9%、半路、跳空 3%、尾盘强势等"近似涨停"全部失效甚至巨亏。
    • ⚠️ 可执行性复核（2026-09-08 新增）：原口径假设能以"昨日涨停价"无限买入。加入真实成交约束重测后：
      • 若只能次日开盘价成交且一字/顶板开盘（开盘即涨停）买不进 → 板家族全线转负（board_hold 1.89→-0.17，board_1d 1.85→-0.27）。因为打板利润几乎全部来自"昨日涨停价→次日高开"的隔夜溢价，而该价格现实中排队买不到。
      • 若采用更贴近实战的排板口径（涨停但非一字开盘→按涨停价排队买入）→ 折价但仍显著为正：board_hold 1.59 / 55.6%、board_1d 1.55 / 50.1%、board_shrink 1.16 / 17.6%。
      • 结论：打板 alpha 真实存在但被高估 ~20-25%（1.89→1.55~1.59）；无论何种口径都远优于近似信号。"次日开盘追高买"是亏损口径，实战只能排板或尾盘。

第二部分：分类详解

A. 短线 / 打板家族（19 个）—— 唯一的真实 alpha

打板家族的核心信号是**"涨停"（涨跌停制度下的事前信息）**，次级信号（跳空、涨幅、半路、尾盘强势）全面失效。越贴近"涨停"越强，越像"强势"越弱。

⚠️ 可执行性提示（2026-09-08 复核）：下表夏普为"理想成交"口径（按昨日涨停价无限买入）。加入真实成交约束后需整体折价：

  • 排板口径（涨停但非一字开盘 → 可排队按涨停价成交）：board_hold 1.59、board_1d 1.55、board_shrink 1.16，仍显著为正。
  • 次日开盘口径（只能次日开盘买，开盘即涨停则买不进）：全线转负（约 -0.1 ~ -0.3），因为利润来自"涨停价→次日高开"的隔夜溢价，该价买不到。
  • ③ 排板口径样本外验证：board_1d OOS 1.73、board_hold/dragon/first OOS 1.55~1.59、shrink OOS 仅 0.80（全样本 1.42 需打折到 <1.0）。raw 口径 OOS 全线衰减至 1.4~1.7。
  • 实战含义：打板必须走排板/回封/尾盘路径，不可次日竞价追高；折价后夏普 1.55~1.73 样本外复现，仍是全场唯一攻击型短线；缩量板样本外失效。

第三部分：方法论总结（工程经验）

  1. 数据与口径：统一口径 2019-2026 / 成本 0.15% / 月调；短线副线需日频再平衡（D调）才公平。口径必须统一对比，否则"月调 vs 日调"会误导。
  2. 前视偏差红线：信号必须在 t-1 日收盘生成、T 日建仓、T 日净值含建仓当日收益。曾因信号泄露产生 45000% 的假值，修掉后见真实结果。
  3. 集成优于单策略、组合优于优化器：
    • 曲线级融合（2.01）>> 权重级复现（1.00）；
    • 3~6 条高夏普策略等权/RP 为最优规模；
    • Markowitz/MinVar 等优化器因估计误差败给简单加权。
  4. 杠杆使用条件：波动目标只在"分散度极高 + 回撤极浅"的组合上（如全资产 RP）才有正贡献；对任何单资产或高波动组合加杠杆都是降低夏普。
  5. 风险预算与护栏：窄止损（海龟 2ATR）、趋势过滤（SMA200/120）能有效压回撤；但大盘 MA20 过滤、情绪过滤这类"晚确认"信号反而帮倒忙。
