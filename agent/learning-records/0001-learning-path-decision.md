# 0001: 确定学习路径与第一课方向

## 日期
2026-06-26

## 决策
- 学习目标调整为：学习 AI Agent 的底层知识，具备阅读 AI 论文的能力
- 不限定领域，但实践聚焦于 code agent 基础设施
- 第一课选定为「如何阅读 AI 论文」

## 原因
- 用户无 AI/ML 背景，需要从基础开始
- 阅读论文是从第一手来源获取知识的核心技能
- Code Agent 领域的发展速度使论文成为最可靠的知识源

## 影响
- 后续课程将围绕论文中出现的概念逐步深入
- 术语表（reference/glossary.html）作为持续更新的参考文档
- 每课应推荐一篇相关论文作为课外阅读
