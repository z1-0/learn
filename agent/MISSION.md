# Mission: 理解 AI Agent，构建 coding 基础设施

## 愿景
我想系统性地学习 AI Agent——它的核心概念、架构、能力边界——**不限定领域**。但我的实践场景和关注点放在 coding 和 developer experience 上，尤其是 code agent 相关的基础设施建设。

## 为什么重要
- AI Agent 正在重塑软件开发的方式，这是工程师不能忽视的趋势
- 我想成为**构建者**，而不仅仅是使用者——为 code agent 搭建基础设施
- 理解 Agent 的底层原理是做基础设施的必要前提

## 成功标准
- [ ] 理解 AI Agent 是什么、如何工作、能做什么和不能做什么
- [ ] 能够搭建 code agent 相关的基础设施（沙箱、评估、工具集成等）
- [ ] 具备评价和比较不同 Agent 架构/框架的能力
- [ ] 能够设计和实现简单的 Agent 系统

## 约束
- 没有 AI/ML 背景——从基础开始
- 学习范围不限定领域，但实践聚焦在 code agent 基础设施
