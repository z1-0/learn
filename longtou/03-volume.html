CHAPTER 03

量能

前置：02 ｜ 预计 10 分钟 ｜ 攻在量中，退在量后

看盘先看量，量是市场人气的体温计。配合周期那章用。

1. 四个基础量

放量
有人拼命买，有人拼命卖，成交活跃。分歧大，方向马上要出来
缩量
所有人看法一致，没人愿意换手。没分歧，但也没人进场
天量
量能创近期新高。买盘一把打光，后面难再有更大的量，容易见顶（天量天价）
地量
量能创近期新低。没人交易了，抛压枯竭，变盘临界点（地量地价）
量是结果不是原因

先有分歧才有量，先有共识才有缩量。看到量先问一句：这量是哪来的？是抢筹还是出货？

2. 五种量价组合

组合含义看位置
放量上涨资金真金白银进场，温和放量最健康低位 = 启动；高位 = 盯滞涨
缩量上涨筹码锁仓，没人舍得卖低位 = 惜售还能走；高位缩量加速最危险，哪天放量分歧就是大面
放量换手（十字星）横盘换手消化分歧，浮筹出清，后面上涨阻力小低位 = 洗盘；高位 = 出货嫌疑
放量下跌分歧兑现低位 = 恐慌盘一次出清，反弹阻力反而小；高位 = 主力出货，反弹是逃命（核按钮）
缩量下跌没人接盘，阴跌不止越跌越缩 = 没人抄底，反弹就被砸
判断口诀

低位放量是换手，高位放量是出货；低位缩量是惜售，高位缩量是锁仓。同样的量，位置不同，意思完全相反。

3. 四个实战例子

  1. 缩量回调 + 再次放量突破 = 标准启动买点。回调时没人卖，再突破时真金白银进场，洗盘结束的信号。
  2. 低位持续放量 + 股价不跌 = 主力吸筹。一直有人买，价格却压着不动。埋伏坐等拉升，但时间没准头，别满仓赌。
  3. 高位放量滞涨 + 收长上影 = 当天跑路，绝不留恋。天量都没能把价格抬上去，买盘已经打光了，次日大概率阴。
  4. 连续缩量阴跌 + 地量星线 = 短期反弹临界点。注意只是博反弹不是反转，反弹到压力位就要走。

4. 超短视角（打板接力用）

  • 竞价量：竞价量占昨日全天量的比例。放量高开 = 资金抢筹；缩量高开 = 虚火，开盘容易浇灭（具体阈值见第 07 章）。
  • 涨停的量能：首板放量、换手充分 = 健康；一字板缩量 = 锁仓，接力要等它分歧换手，直接追一字是给里面的人抬轿。
  • 弱转强必须放量：缩量翻红不可信，没有量就是没人认可，翻红也是假的。
  • 高位巨量长阴：炸板巨量、放量长阴，都是出货现场，别去接。
  • 量价背离：价创新高，量不创新高，涨不动了，警惕随时回落。
一句话用量能

看任何一根 K 线，先看量再定价：放量看方向，缩量看位置，天量跑路，地量等反弹。
