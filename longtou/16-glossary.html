附录：术语表

工具章 ｜ 口径以本教程为准，不同软件的统计口径可能有差异

1. 统计口径

术语本教程口径
涨停收盘价达到当日涨停价（主板 10cm，见第 01 章）
炸板盘中触及涨停后又打开，收盘未封住
炸板率炸板家数 ÷（涨停家数 + 炸板家数）。经验阈值 >30% = 情绪差。不同软件分母口径略有差异，复盘时固定用一种即可
晋级率昨日涨停股中今日继续涨停的比例。越高说明接力赚钱效应越强
大面昨日涨停、今日跌超 7% 的个股（10cm 主板口径）。比例越大亏钱效应越强
溢价昨日买入/涨停的票，今日的收益。涨停次日溢价是情绪的直接读数
连板 / 断板连续涨停 / 中断涨停
空间板当前市场最高的连板高度，情绪的天花板

2. K 线与走法

术语含义
首板第一板，行情的起点
换手板放充分换手后封的板，筹码成本抬高，接力质量高
一字板开盘即封死涨停，买不到；缩量一字 = 锁仓
秒板开盘几秒内封板
烂板反复炸板、封了开开了封的板，分歧巨大
回封炸板后重新封上涨停
首阴强势上涨后的第一根阴线，反包博弈的标的（第 06 章）
反包次日用阳线/涨停把首阴吃掉
弱转强昨天弱（低开/大阴），今天竞价与盘中走强，必须放量
核按钮高位票被大单直接砸向跌停的出货走势（第 11 章）
天地板 / 地天板单日涨停到跌停 / 跌停到涨停
地量 / 天量阶段最低/最高成交量，对应变盘临界 / 见顶信号（第 03 章）

3. 龙头与梯队

术语含义
龙头带动板块的那只，不是涨得最高的那只（第 05 章）
总龙头全场高度最高、跨板块带节奏的票
卡位同身位中另一只先封板、封单更硬，取代原龙头
补涨龙总龙头倒下后，同题材低位接力的票，高度低于总龙
跟风 / 杂毛龙头涨它才涨的票，不碰
梯队当日各连板高度的分布（第 05 章）
主线当前资金聚集、连板最多、持续性最好的题材（第 04 章）
一日游当天涨停潮、次日就散的题材

4. 情绪与周期

术语含义
情绪周期启动 → 发酵 → 高潮 → 循环的赚钱/亏钱效应节奏（第 02 章）
退潮亏钱效应扩散的阶段，空仓或只做首板
冰点情绪最低点，常伴随地量，之后可能有修复
修复 / 反弹退潮中的反弹，可能是假修复，用仓位试不用判断赌
赚钱效应 / 亏钱效应买涨停能赚 / 买涨停就亏的市场状态

5. 交易动作

术语含义
打板在涨停价买入，分排板与扫板（第 09 章）
排板涨停价挂单排队等成交
扫板涨停瞬间主动吃掉卖单成交
半路涨停前的分时低点不破 + 放量翻红处买入
低吸回调不破关键位时买入，止损必须明确
接力买入昨日涨停股，博次日溢价
竞价抢筹竞价高开超预期时买入（第 07 章）
核按钮（动作）不计成本砸卖出；与走势名词同形
排单跑跌停时第一时间挂跌停价排队卖出（第 11 章）
模式内 / 模式外符合 / 不符合自己既定计划与系统（第 12、13 章）
