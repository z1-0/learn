CHAPTER 06

涨停次日的四种走法

前置：05 ｜ 预计 15 分钟 ｜ 全教程的定性中枢：一切操作先归类到四种走法之一

涨停的次日，无非四种走法或者是他们的延伸。

四种走法速览

① 接着涨停（★★★ 主升延续）：看上板时间、封单力度 —— 接不接？
② 大阳线，没封住（★★ 强势未完）：看量能、收盘位置 —— 拿还是加？
③ 高开低走（★ 分歧转弱）：看首阴性质、反包条件 —— 走，还是赌反包？
④ 低开趴水下（☆ 退潮走弱）：看有没有弱转强 —— 止损点画哪儿？

两条铁律

① 怎么走只由事实决定，不由愿望决定。低开就是低开，别拿"主力洗盘"安慰自己。
② 走法会往下掉：大阳冲高回落就成了高开低走；高开低走反包失败就成了趴水下。心里记着"它是从哪一档掉下来的"，超短的盈亏全在这一落一升里。

1. ① 接着涨停（连板）

涨停次日竞价还猛、又上板，就是连板。别看别的，就看两样：上板时间和力度。

上板时间（越早越强）

时段性质
秒板（竞价一字 / 9:30-9:35）预期拉满，资金锁死。但换手不够的秒板，隔天有溢价却接不动
早盘板（9:35-10:00）主动进攻，资金坚决，质量最高
上午板（10:00-11:30）正常晋级，盘中分歧完又合上
午后板（13:00-14:00）分歧修复，拉锯完多头赢
尾盘板（14:00-14:57）被动封板，偷鸡性质，次日溢价最差
尾盘偷袭 / 收盘集合竞价板（14:57-15:00）最后三分钟把价顶上涨停，最弱，多半是隔日诱多

力度（封得住、不炸、量合理 = 强）

封单
封单额 / 流通市值，小票 ≥5%、大票看绝对金额。封单稳、还一直加单 = 强；反复撤了又挂 = 筹码不稳
炸板回封
一次封死不炸 = 最强；炸了又回封好几次 = 巨大分歧，弱
换手率
缩量板（没人舍得卖）强于巨量板。巨量 + 高换手 = 换手换庄，次日大概率见顶
板块地位
同高度里谁先封、谁的封单先堆上去，卡位的就是真龙头（第 05 章）

连板就是"接力游戏"。别想"它明天还能板吗"，要想"今天这情绪，这个高度还接不接得住"。看两个数：同批涨停里几个晋级（晋级率）、今天炸了几个（炸板率，经验阈值 >30% 就是情绪差）。

次日怎么弄

  • 一字/秒板还缩量 → 别追，等分歧换手再说（不是更强就是见顶）。
  • 换手板接着晋级 → 弱转强，最强接力玩法。
  • 3 板以上的高位板 → 一断板就是信号，别等反包，跑就完事（卖出细则见第 11 章）。

2. ② 大阳线，没封住

涨停次日冲了一把没封住，收了根 5%-9% 的大阳线（10cm 主板口径）。这根线强不强，看它离涨停多近、放量多少、收在哪。

复盘三看

  1. 量能：比昨天涨停放量 = 分歧加大；缩量阳线 = 没人卖，还能走。
  2. 收盘位置：收在最高点附近（光头大阳）= 强势没完；上影线长 = 冲高就回落，抛压现形。
  3. 是不是新高：创了阶段新高 = 空间打开；被前高压住 = 上头全是套牢盘。

接下来怎么走

  • 大阳 = 涨停"差一口气没封住"，不算走弱，顶多算话没说完。次日三种走法：
    • 惯性高开接着涨 → 反包涨停，回到第 ① 种。
    • 平开横盘 → 洗盘换手，还能拿。
    • 冲高回落 → 那就按高开低走（第 ③ 种）办。

怎么操作：拿着为主，别自己下车；突破前高 + 放量才想着加仓。大阳次日别瞎追高，你接的不是涨停，是根"没封住"的阳线，溢价得打折扣。

3. ③ 高开低走（首阴与反包）

涨停次日高开冲一把，然后一路阴回去。这是分歧最大、最考手艺的走法。这一节的干货：首阴和反包。

什么是"首阴"

  • 一波强势上涨（尤其是涨停）之后的第一根阴线。
  • 看位置：加速后高位的第一根阴线，才有反包博弈价值；低位正常回调的阴线不算数。

首阴的两种性质（先定性，再谈操作）

洗盘型首阴

量能温和/缩量 ｜ 收盘守住关键支撑（5 日线 / 涨停开盘价）｜ 板块还在、板块内仍有涨停 → 主力洗盘，还能赌反包。

出货型首阴

巨量长阴 ｜ 收盘破位、甚至跌停 ｜ 板块整体退潮 → 资金跑路，反弹是逃命。

口诀：量不暴、位不破、板块不散 = 洗盘；巨量 + 破位 + 板块退 = 出货。三条里中了两条，就按出货算。

反包

  • 反包 = 下一两天把首阴收回来，最好直接涨停，把阴线一口吃掉。
  • 反包成立得占三条（至少前两条）：
    1. 竞价弱转强：低开/平开变高开，或者大幅低开后很快翻红（第 07 章）；
    2. 分时不破前低，翻红有量（第 08 章）；
    3. 板块情绪回暖和（或）个股重新变成板块焦点。
  • 反包买点：竞价高开超预期（抢竞价），或者分时低点不破 + 放量翻红（半路）。买点细节见第 09 章。
  • 反包失败：反弹没量、冲高回落、或又创首阴新低，马上按第 ④ 种止损。反包只赌一次，不接第二次。

4. ④ 低开趴水下

涨停次日竞价直接低开，全天趴均价线下头。最弱的一种，就干一件事：把止损点画好，再看看还有没有弱转强的可能。

复盘四看

  1. 跌停还是深跌：跌停 = 恐慌出逃，基本没戏；深跌没跌停 = 还有人接。
  2. 破没破关键位：5 日线、昨天涨停的开盘价、分时均价线，破了就没博弈价值了。
  3. 量是啥性质：缩量阴跌 = 没人接，阴跌没完；放量下跌 = 明摆着出货。
  4. 它什么地位：主线龙头抗跌，还能等弱转强；跟风杂毛直接扔，没有低吸价值。

弱转强（唯一值得等的反攻）

大幅低开 → 急杀稳住了 → 放量翻红收回均价线/前低。这套动作出来了才跟，没出来就按纪律走人。

止损纪律

  • 触发了就走，别跟"主力洗盘"谈恋爱：
    • 跌破昨天涨停的开盘价；
    • 跌破 5 日线、收盘没收回；
    • 板块退潮 + 个股也弱（双杀），无条件清。
  • 到了这一步，只谈止损，不谈补仓摊平。超短的钱就是靠管住单笔亏损来的（仓位细则见第 10 章）。

5. 竞价同理

高开 3%+
强，预期接着涨停或大阳线
高开 <3% / 平开
分歧，重点盯高开低走（会不会冲高就阴）
低开
弱，按第 ④ 种画好止损点，或者等弱转强
